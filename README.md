# Automotive Trends EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on an automotive dataset containing 600 vehicle records.

The analysis focuses on vehicle types, brands, regions, fuel types, prices, units sold, and customer ratings.

## Objectives

- Understand automotive sales trends
- Analyze sales by vehicle type
- Compare brands based on units sold
- Analyze regional sales performance
- Study vehicle price distribution
- Analyze customer ratings
- Identify and handle missing values
- Detect and handle outliers

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

- ## Dataset

The dataset contains 600 automotive records.

Main variables include:

- Date
- Vehicle Type
- Brand
- Region
- Fuel Type
- Price
- Units Sold
- Customer Rating
- Age Group

## Data Cleaning

Missing values were handled using median imputation for numerical variables and mode imputation for categorical variables.

Outliers were detected using the Interquartile Range (IQR) method and handled using capping.

## Visualizations

The project includes:

1. Total Vehicle Sales by Vehicle Type
2. Total Vehicle Sales by Brand
3. Total Vehicle Sales by Region
4. Distribution of Vehicle Prices
5. Distribution of Customer Ratings

## Conclusion

The analysis provides insights into automotive sales patterns across vehicle types, brands, and regions while demonstrating the complete Exploratory Data Analysis workflow using Python.
